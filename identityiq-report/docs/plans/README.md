# Project plans

Approved project plans for this repository live here, one markdown file per
plan, committed as designed (with an *Outcome* note when reality diverged).

## Naming convention

```
YYYY-MM-DD-<short-kebab-slug>.md
```

- `YYYY-MM-DD` — the date the plan was approved. Dated prefixes keep the
  directory chronologically sorted and collision-free.
- `<short-kebab-slug>` — a few lowercase, hyphen-separated words describing
  the change, e.g. `report-post-rule-and-dashboard-app`.

New plans must follow the same convention.
